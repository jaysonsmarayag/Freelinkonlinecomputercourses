# Free Links to Computer Learning

A responsive JavaScript dashboard for browsing public free-audit courses and learning resources.

## Features

- Dashboard overview with course statistics
- Searchable course library
- Subject filters
- Home, courses, notes, and license pages
- Copy-page-link action
- Responsive desktop and mobile layout
- No runtime dependencies

## Run locally

```powershell
npm start
```

Open `http://127.0.0.1:8080`.

You can also open `index.html` directly, though a local server is recommended.

## Validate JavaScript

```powershell
npm run check
```

## Project files

- `index.html` - application entry point
- `app.js` - routing, dashboard, filtering, and page rendering
- `catalog.js` - course catalog data
- `server.js` - dependency-free local Node.js server
- `static/style.css` - responsive application styles
- `static/poster.webp` - page poster artwork
- `LICENSE` - project ownership and reuse terms
